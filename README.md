## 📖 4. Hướng Dẫn Xem Các Bài Tập Thực Hành PHP HNMU (`Buoi1` - `Buoi9`)

Để xem chi tiết nội dung và file thực hành của từng buổi học, bạn thực hiện theo các bước đơn giản sau:

### 🔹 Cách 1: Xem trực tiếp từ giao diện Portfolio (Khuyên dùng)
1. Mở trang `about.php` trên trình duyệt.
2. Cuộn xuống mục **🚀 Dự Án AI Nổi Bật**.
3. Tìm thẻ dự án **Learn Prj Php with Hnmu**.
4. Nhấp vào các nút **Buổi 1**, **Buổi 2**, ..., **Buổi 9**.
5. Giao diện từng buổi học sẽ tự động liệt kê các file bài tập, mã nguồn và xem trước hình ảnh/bản vẽ của buổi đó.
6. Nhấn nút **⬅ Quay lại Trang chủ** để trở về trang chính.

### 🔹 Cách 2: Xem trực tiếp qua đường dẫn thư mục
Bạn cũng có thể truy cập thẳng vào thư mục bài tập của buổi mong muốn:
